# CLAUDE.md

This project's agent instructions are tool-agnostic and live in
**[AGENTS.md](AGENTS.md)** — read it. The component/module map it refers to is
**[ARCHITECTURE.md](ARCHITECTURE.md)**.

Two things to internalize before editing:

1. **Use the vocabulary in `ARCHITECTURE.md`** — refer to components and modules
   by their real names.
2. **Keep `ARCHITECTURE.md` in sync** — when you add, remove, rename, or
   materially change a component, module, API route, or stored data shape,
   update the matching entry in the same change. (Skip it for pure bug fixes or
   style tweaks that don't change structure.)

Everything else — commands, how to verify changes, and conventions — is in
[AGENTS.md](AGENTS.md).
